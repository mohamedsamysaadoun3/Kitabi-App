# 📖 كتبي - Kitabi

تطبيق قراءة كتب عربي بالذكاء الاصطناعي | Arabic AI-Powered Book Reader

## ✨ المميزات

### 📚 مكتبة الكتب
- كتب محلية (PDF, EPUB, TXT) من جهاز المستخدم
- كتب أونلاين من متجر مجاني (Open Library + Google Books + Gutenberg)
- تصنيفات عربية شاملة (روايات، علوم، تاريخ، فلسفة، شعر...)

### 🤖 كتبي AI
- **Mistral Large** - شات ذكي، تلخيص، شرح، ترجمة، أسئلة فهم
- **HuggingFace** - ترجمة متخصصة (عربي↔إنجليزي)، تحليل مشاعر
- **TTS عربي** - تحويل النص لكلام بالعربي
- كل الميزات مجانية 100%

### 💬 مراسلة ومناقشة
- غرفة لكل كتاب للمناقشة مع القراء
- اقتباسات من الكتب في الشات
- تفاعلات وردود

### ⭐ تقييمات ومراجعات
- تقييم 1-5 نجوم مع توزيع مرئي
- مراجعات نصية مع زر "مفيد"
- متاحة لكل المستخدمين

### 📊 إحصائيات وعدادات
- عداد مسجلين حقيقي (أونلاين)
- عداد أونلاين دلوقتي
- إحصائيات قراءة شخصية

## 🛠️ التقنيات

| التقنية | الاستخدام |
|---------|-----------|
| Kotlin | اللغة الأساسية |
| Jetpack Compose | واجهة المستخدم |
| Material 3 | التصميم |
| Hilt | حقن التبعية |
| Room | قاعدة بيانات محلية |
| Firebase | مصادقة + Firestore + Realtime DB |
| Mistral AI | الذكاء الاصطناعي |
| HuggingFace | ترجمة + TTS |
| Retrofit | API calls |
| WorkManager | مهام خلفية |
| Coil | تحميل الصور |

## 🏗️ البنية

```
MVVM + Clean Architecture
├── core/          → التصميم والتنقل والمشترك
├── data/          → قواعد البيانات والـ APIs
├── domain/        → النماذج والمستودعات وحالات الاستخدام
├── feature/       → الشاشات والـ ViewModels
├── provider/      → مزودي الكتب والذكاء الاصطناعي
└── di/            → وحدات Hilt
```

## 🚀 التشغيل

1. افتح المشروع في Android Studio

3. شغّل على emulator أو جهاز حقيقي
